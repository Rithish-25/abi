# Abirami Laboratory - Flutter App

Cross-platform (Android + iOS) Flutter prototype for Abirami Laboratory, a blood testing lab in Thindal, Erode.

## Setup

This zip contains only the `lib/`, `pubspec.yaml`, and `analysis_options.yaml` — the Dart source of the app.
Flutter's native Android/iOS/web platform folders are generated by the Flutter CLI on your machine (they contain
machine-specific build files that can't be shipped generically). To run the app:

```bash
flutter create --org com.abiramilab abirami_laboratory
cd abirami_laboratory
# replace the generated lib/ and pubspec.yaml with the ones from this zip
flutter pub get
flutter run
```

## Structure

- `lib/theme` - design tokens (colors, text styles, spacing) matching the design system
- `lib/models` - data models (BloodTest, Package, Booking, FamilyMember, Address, etc.)
- `lib/data` - mock/seed data (tests, packages, bookings, reports, notifications, doctor referrals)
- `lib/state` - single `AppState` (ChangeNotifier via Provider) holding navigation + all app state, mirroring the
  interactive prototype: cart, bookings, family members, addresses, doctor referrals, notifications
- `lib/widgets` - shared components: PrimaryButton, OutlineButton, AppCard, StatusBadge, BottomNavBar
- `lib/screens` - one file per screen (30 screens): splash, onboarding, login, OTP, home, search, catalogue,
  test details, cart, booking flow, bookings/reports/records lists & detail viewers, notifications, profile,
  family members, saved addresses, and the full doctor module (login, dashboard, referral, reports, commission)
- `lib/main.dart` - app entry, routes all screens through a single Navigator-free screen switch (matches the
  clickable prototype's navigation model) with the bottom tab bar shown on the 5 root tabs

## Design system

Primary #2563EB, Secondary (teal) #14B8A6, Background #F8FAFC, Surface #FFFFFF, Text #0F172A / #64748B,
Border #E2E8F0, Success #22C55E, Warning #F59E0B, Danger #EF4444. Inter typeface (via google_fonts).
Buttons: 52px height, 14px radius. Cards: 16px radius, soft shadow, 1px border. 8-point spacing grid.
